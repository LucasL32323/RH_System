````markdown
# HR-Auto

Aplicação automatizada de Recursos Humanos — TCC Técnico em Desenvolvimento de Sistemas, SENAI Santos (2026).

## Estrutura

```
HR-Auto/
├── backend/                 # C# / .NET 8 — Clean Architecture

│   ├── src/
│   │   ├── HRAuto.Domain/          # entidades, value objects, regras puras

│   │   ├── HRAuto.Infrastructure/  # EF Core + SQLite, relógio, arquivos
│   │   └── HRAuto.Api/             # controllers, Swagger, JWT (Fase 4)

├── database/                # modelo_fisico_sqlite.sql (25 tabelas) — entra na Fase 2

Regra de dependência (back-end): `Api → Infrastructure → Application → Domain`. O Domain não conhece ninguém.

## Back-end

Requisito: .NET SDK 8.

```bash
cd backend
dotnet restore
dotnet build
dotnet test
dotnet run --project src/HRAuto.Api --launch-profile https
```

- Swagger: https://localhost:7080/swagger
- Health check: https://localhost:7080/health
- Status: https://localhost:7080/api/v1/sistema/status

Na primeira vez: `dotnet dev-certs https --trust`.

## Front-end

Requisito: Flutter 3.22+ (Dart 3.4+).

```bash
cd frontend
flutter create --platforms=android,ios,web --project-name hr_auto --org br.senai.hrauto .
flutter pub get
flutter analyze
flutter test
flutter run -d chrome --dart-define=API_URL=http://localhost:5080
```

O `flutter create .` só adiciona as pastas de plataforma; ele não sobrescreve `lib/`, `test/` nem `pubspec.yaml` já existentes. Se perguntar, mantenha os arquivos do projeto.

No emulador Android use `--dart-define=API_URL=http://10.0.2.2:5080`.

## Convenções

- Commits por funcionalidade, mensagens em português no imperativo (ex.: `Adiciona registro de ponto`).
- Código do funcionário: `FUNC-0001` (derivado de `id_funcionario`); busca sempre pelo código.
- Paleta: `#1E3A8A` (principal), `#3B82F6` (destaque), `#93C5FD` (apoio), fundo `#F8FAFC`, texto `#0F172A`; fonte Inter.
- Perfis: Colaborador, RH, Admin. "Gestor" é quem aparece como `id_gestor` de outros funcionários.
````

```csharp
namespace HRAuto.Application.Common;

/// <summary>
/// Resultado de um caso de uso: sucesso com valor ou falha com mensagem.
/// Evita usar exceções para fluxos esperados (ex.: senha inválida, batida fora de ordem).
/// </summary>
public sealed class Resultado<T>
{
    public bool Sucesso { get; }
    public T? Valor { get; }
    public string? Erro { get; }

    private Resultado(bool sucesso, T? valor, string? erro)
    {
        Sucesso = sucesso;
        Valor = valor;
        Erro = erro;
    }

    public static Resultado<T> Ok(T valor) => new(true, valor, null);

    public static Resultado<T> Falha(string erro)
    {
        if (string.IsNullOrWhiteSpace(erro))
            throw new ArgumentException("A mensagem de erro é obrigatória.", nameof(erro));
        return new(false, default, erro);
    }
}
```

```csharp
namespace HRAuto.Domain.Common;

/// <summary>
/// Base das entidades persistidas. Todas as tabelas do modelo físico usam
/// chave primária inteira autoincrementada.
/// </summary>
public abstract class EntidadeBase
{
    /// <summary>Chave primária (id_* da tabela correspondente).</summary>
    public int Id { get; protected set; }

    // Igualdade por identidade: duas entidades são iguais se tiverem o mesmo tipo e o mesmo Id (> 0).
    public override bool Equals(object? obj)
    {
        if (obj is not EntidadeBase outra) return false;
        if (ReferenceEquals(this, outra)) return true;
        if (GetType() != outra.GetType()) return false;
        return Id != 0 && Id == outra.Id;
    }

    public override int GetHashCode() => HashCode.Combine(GetType(), Id);
}
```

### backend/src/HRAuto.Domain/ValueObjects/CodigoFuncionario.cs

```csharp
using System.Globalization;
using System.Text.RegularExpressions;
using HRAuto.Domain.Common;

namespace HRAuto.Domain.ValueObjects;

/// <summary>
/// Código do funcionário no formato FUNC-0001 (RF11/RF13).
/// É derivado de FUNCIONARIO.id_funcionario: por isso é único, sequencial e imutável.
/// A busca na tela de funcionários é feita pelo código, não pelo nome.
/// </summary>
public readonly record struct CodigoFuncionario
{
    private const string Prefixo = "FUNC-";
    private static readonly Regex Padrao =
        new(@"^FUNC-(\d{4,9})$", RegexOptions.Compiled | RegexOptions.IgnoreCase | RegexOptions.CultureInvariant);

    /// <summary>Id do funcionário (id_funcionario).</summary>
    public int Id { get; }

    /// <summary>Texto no formato FUNC-0001.</summary>
    public string Valor => Formatar(Id);

    public CodigoFuncionario(int id)
    {
        if (id <= 0) throw new DominioException("O id do funcionário deve ser maior que zero.");
        Id = id;
    }

    /// <summary>Gera o texto FUNC-NNNN (mínimo de 4 dígitos) a partir do id.</summary>
    public static string Formatar(int id)
    {
        if (id <= 0) throw new DominioException("O id do funcionário deve ser maior que zero.");
        return Prefixo + id.ToString("D4", CultureInfo.InvariantCulture);
    }

    /// <summary>
    /// Lê um texto digitado na busca (aceita minúsculas e espaços nas pontas).
    /// Retorna false se o formato não for FUNC- seguido de 4 a 9 dígitos, ou se o id for zero.
    /// </summary>
    public static bool TentarConverter(string? texto, out CodigoFuncionario codigo)
    {
        codigo = default;
        if (string.IsNullOrWhiteSpace(texto)) return false;

        var m = Padrao.Match(texto.Trim());
        if (!m.Success) return false;

        if (!int.TryParse(m.Groups[1].Value, NumberStyles.None, CultureInfo.InvariantCulture, out var id) || id <= 0)
            return false;

        codigo = new CodigoFuncionario(id);
        return true;
    }

    public override string ToString() => Valor;
}
```

```csharp
using HRAuto.Application.Abstractions;

namespace HRAuto.Infrastructure.Tempo;

/// <summary>
/// Relógio do servidor no fuso de Brasília. Aceita um "provedor de hora UTC" para permitir testes.

{

    private readonly TimeZoneInfo _fuso;

    public RelogioBrasilia() : this(() => DateTimeOffset.UtcNow) { }

    public RelogioBrasilia(Func<DateTimeOffset> utcAgora)
    {
        _utcAgora = utcAgora;
        _fuso = ObterFusoBrasilia();
    }

    public DateTimeOffset Agora() => TimeZoneInfo.ConvertTime(_utcAgora(), _fuso);

    public DateOnly Hoje() => DateOnly.FromDateTime(Agora().DateTime);

    // Linux/macOS usam o id IANA; Windows usa o id próprio. Tenta os dois.
    private static TimeZoneInfo ObterFusoBrasilia()
    {
        foreach (var id in new[] { "America/Sao_Paulo", "E. South America Standard Time" })
        {
            try { return TimeZoneInfo.FindSystemTimeZoneById(id); }
            catch (TimeZoneNotFoundException) { /* tenta o próximo id */ }
            catch (InvalidTimeZoneException) { /* tenta o próximo id */ }
        }

        // Último recurso: UTC-3 fixo (o Brasil não usa horário de verão desde 2019).
        return TimeZoneInfo.CreateCustomTimeZone("BRT", TimeSpan.FromHours(-3), "Brasília", "Brasília");
    }
}
```

```dart
import 'dart:async';
import 'dart:convert';

import 'package:http/http.dart' as http;

import '../config/app_config.dart';

/// Erro de comunicação com a API, com mensagem pronta para exibir ao usuário.
class ApiException implements Exception {
  ApiException(this.mensagem, {this.statusCode});

  final String mensagem;
  final int? statusCode;

  @override
  String toString() => 'ApiException($statusCode): $mensagem';
}

/// Cliente HTTP único do app. Na Fase 4/5 passa a enviar o token JWT no cabeçalho.
class ApiClient {
  ApiClient({http.Client? cliente, String? baseUrl})
      : _cliente = cliente ?? http.Client(),
        _baseUrl = baseUrl ?? AppConfig.apiBaseUrl;

  final http.Client _cliente;
  final String _baseUrl;

  /// GET que devolve o JSON (objeto) da resposta.
  Future<Map<String, dynamic>> getJson(String caminho) async {
    final uri = Uri.parse('$_baseUrl$caminho');
    try {
      final resposta = await _cliente
          .get(uri, headers: {'Accept': 'application/json'})
          .timeout(AppConfig.timeoutApi);

      if (resposta.statusCode < 200 || resposta.statusCode >= 300) {
        throw ApiException(
          'A API respondeu com erro ${resposta.statusCode}.',
          statusCode: resposta.statusCode,
        );
      }

      final corpo = jsonDecode(utf8.decode(resposta.bodyBytes));
      if (corpo is! Map<String, dynamic>) {
        throw ApiException('Resposta da API em formato inesperado.');
      }
      return corpo;
    } on TimeoutException {
      throw ApiException('A API demorou demais para responder.');
    } on http.ClientException {
      throw ApiException('Não foi possível conectar à API.');
    } on FormatException {
      throw ApiException('Resposta da API em formato inesperado.');
    }
  }

  void dispose() => _cliente.close();
}
```

### frontend/lib/core/utils/codigo_funcionario.dart

```dart
/// Código do funcionário (FUNC-0001). Espelha a regra do back-end (RF11/RF13):
/// a busca é feita pelo código, nunca pelo nome.
class CodigoFuncionario {
  CodigoFuncionario._();

  static final RegExp _padrao = RegExp(r'^FUNC-(\d{4,9})$', caseSensitive: false);

  /// Gera FUNC-NNNN (mínimo de 4 dígitos) a partir do id.
  static String formatar(int id) {
    if (id <= 0) {
      throw ArgumentError.value(id, 'id', 'deve ser maior que zero');
    }
    return 'FUNC-${id.toString().padLeft(4, '0')}';
  }

  /// Lê o texto digitado na busca e devolve o id, ou null se o formato for inválido.
  static int? tentarConverter(String? texto) {
    if (texto == null) return null;
    final m = _padrao.firstMatch(texto.trim());
    if (m == null) return null;
    final id = int.parse(m.group(1)!);
    return id > 0 ? id : null;
  }
}
```

```bash
#!/usr/bin/env bash
# Inicia o repositório Git do HR-Auto com um commit por parte da fundação.
# Uso: rode na raiz do projeto (a pasta que contém backend/ e frontend/).
set -euo pipefail

if [ ! -d backend ] || [ ! -d frontend ]; then
  echo "Execute na raiz do projeto (pasta com backend/ e frontend/)." >&2
  exit 1
fi

if [ -d .git ]; then
  echo "Já existe um repositório Git aqui. Nada a fazer."
  exit 0
fi

git init -b main

git add .gitignore README.md scripts
git commit -m "Adiciona README, .gitignore e scripts de apoio"

git add backend
git commit -m "Cria solução .NET com Clean Architecture e endpoint de status"

git add frontend
git commit -m "Cria base do app Flutter com tema, MVVM e tela de conexão"

echo
echo "Repositório criado. Para publicar no GitHub:"
echo "  git remote add origin <URL-do-repositorio>"
echo "  git push -u origin main"
```
