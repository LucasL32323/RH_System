## O que esta fase entrega
- **Login JWT (RF01, RNF04, RNF05)**: `POST /api/v1/auth/login` com e-mail e senha (BCrypt custo 11). Token HS256 de 8 h com `sub` (usuário), `fid` (funcionário), `codigo` (FUNC-0007), `name`, `email` e `role` (Colaborador/RH/Admin). Mesma mensagem para e-mail inexistente, senha errada e conta inativa; conta inexistente também gasta um BCrypt (tempo de resposta igual); login e falhas vão para o log de auditoria (RF08).
- **Perfis (RF05, RF07)**: "seguro por padrão": a política de fallback exige login em tudo que não tenha `[AllowAnonymous]`. Políticas `RhOuAdmin` e `Admin` já registradas para as próximas fases.
- **Senha (RF03, RF04)**: `POST /auth/alterar-senha` (logado) e `POST /auth/esqueci-senha` + `POST /auth/redefinir-senha`. O link por e-mail leva um token assinado (30 min, uso único, chave e público diferentes do token de acesso, não serve para logar). Política de senha: mínimo 8, maiúscula, minúscula, número e símbolo, máximo 72 bytes (limite do BCrypt).
- **Ponto (RF17 a RF21, RF24, RF25)** em casos de uso sobre as regras da Fase 3: `GET /ponto/hoje`, `POST /ponto/batidas` (horário do servidor), `POST /ponto/batidas/sincronizar` (fila offline, idempotente, até 100 itens e 7 dias), `GET /ponto/espelho` (próprio; gestor vê a equipe; RH/Admin veem todos). Ao fechar o dia (4ª batida) gera crédito/débito no banco de horas e notifica o gestor se passar de 2 h extras.
- **Infra de API**: ProblemDetails (RFC 7807) em todos os erros, tratador global de exceções (500 genérico com `traceId`, sem vazar detalhe), limite de tentativas por IP nos endpoints anônimos (429 + Retry-After), corpo máximo de 16 KB (64 KB na sincronização), `Cache-Control: no-store`, CORS configurável, Swagger com botão Authorize, HSTS fora de Development.
- **Persistência**: repositórios EF, unidade de trabalho com transação (ponto + auditoria gravados juntos) e conversão de violação de índice único em 409.

## Suposições (os documentos não definem; confirmar com o grupo)
- Qualquer perfil logado (inclusive RH e Admin) bate o próprio ponto. Perfil vem do token e nunca do corpo da requisição.
- Token de acesso de 8 h e sem refresh token: o JWT não é revogável antes de expirar; logout só registra na auditoria e o app apaga o token. Funcionário desligado perde as operações de ponto na hora (os casos de uso conferem `ativo`), mas o token ainda abre rotas que não conferem.
- Troca de senha com senha atual errada devolve 400 (e não 401) para o app não deslogar o usuário por erro de digitação.
- "Esqueci a senha" responde 202 igual exista ou não a conta; o único 400 é e-mail malformado. Sem tabela para guardar o token (o modelo físico não tem), o uso único vem de uma "impressão" do hash da senha atual dentro do token: trocou a senha, o link antigo morre.
- Sincronização offline: máximo 100 batidas por envio, batidas de até 7 dias atrás (acima disso exige manutenção de ponto), folga de 2 min no relógio do aparelho, itens reordenados pelo servidor, falha de um item não derruba os outros.
- Limite de tentativas por IP (10 por minuto, configurável em `RateLimit`). Atrás de proxy reverso é preciso configurar `ForwardedHeaders`, senão todos os usuários aparecem com o mesmo IP.
- O link de recuperação usa a URL de `App:UrlRedefinicaoSenha` (o Flutter Web usa rota com `#`, por exemplo `https://rh.exemplo.com.br/#/redefinir-senha?token=...`); a rota do app será definida na Fase 5.
- O e-mail só é enviado de verdade com `Email:Host`; sem ele o sistema registra no log (em Development, com o link, para testar).
- Admin de teste só existe em Development (`Seed:CriarAdminDeTeste`). A chave JWT de `appsettings.Development.json` é só para desenvolvimento.

```csharp
using System.Text;

namespace HRAuto.Domain.Seguranca;

/// <summary>
/// Política de senha (RF03, RF04, RNF05): mínimo de 8 caracteres com maiúscula, minúscula, número e símbolo.
/// O máximo é de 72 bytes porque o BCrypt ignora o que passar disso: aceitar mais daria a falsa
/// impressão de que a parte final da senha é conferida.
/// </summary>
public static class PoliticaSenha
{
    public const int TamanhoMinimo = 8;
    public const int TamanhoMaximoBytes = 72;

    public const string MensagemRequisitos =
        "A senha deve ter no mínimo 8 caracteres, com letra maiúscula, letra minúscula, número e símbolo.";

    /// <summary>Devolve a mensagem de erro, ou nulo quando a senha atende à política.</summary>
    public static string? Validar(string? senha)
    {
        if (string.IsNullOrEmpty(senha)) return "A senha é obrigatória.";
        if (Encoding.UTF8.GetByteCount(senha) > TamanhoMaximoBytes)
            return $"A senha é muito longa (máximo de {TamanhoMaximoBytes} bytes).";

        var atende = senha.Length >= TamanhoMinimo
                     && senha.Any(char.IsUpper)
                     && senha.Any(char.IsLower)
                     && senha.Any(char.IsDigit)
                     && senha.Any(c => !char.IsLetterOrDigit(c) && !char.IsWhiteSpace(c));

        return atende ? null : MensagemRequisitos;
    }
}
```

```csharp
using System.Text.RegularExpressions;

namespace HRAuto.Domain.ValueObjects;

/// <summary>
/// E-mail de login (RF01). É sempre guardado e comparado em minúsculas e sem espaços nas pontas;
/// o banco também compara sem diferenciar maiúsculas (índice único ux_usuario_email).
/// </summary>
public static class EmailUsuario
{
    public const int TamanhoMaximo = 254;

    // Validação propositalmente simples (algo@dominio.ext): quem confirma o e-mail de verdade é o envio da mensagem.
    private static readonly Regex Padrao =
        new(@"^[^@\s]+@[^@\s]+\.[^@\s]+$", RegexOptions.Compiled | RegexOptions.CultureInvariant);

    /// <summary>Normaliza o texto digitado. Retorna false se estiver vazio, longo demais ou fora do formato.</summary>
    public static bool TentarNormalizar(string? texto, out string email)
    {
        email = string.Empty;
        if (string.IsNullOrWhiteSpace(texto)) return false;

        var limpo = texto.Trim().ToLowerInvariant();
        if (limpo.Length > TamanhoMaximo || !Padrao.IsMatch(limpo)) return false;

        email = limpo;
        return true;
    }
}
```

```csharp
namespace HRAuto.Application.Common;

/// <summary>
/// Categoria da falha de um caso de uso. A camada Api converte cada uma em um código HTTP
/// (400, 401, 403, 404, 409), sem que a Application precise conhecer HTTP.
/// </summary>
public enum TipoErro
{
    /// <summary>Dado inválido ou regra de negócio violada (HTTP 400).</summary>
    Validacao = 1,
    /// <summary>Credencial inválida ou ausente (HTTP 401).</summary>
    NaoAutenticado = 2,
    /// <summary>Autenticado, mas sem permissão para a operação (HTTP 403).</summary>
    Proibido = 3,
    /// <summary>Registro inexistente (HTTP 404).</summary>
    NaoEncontrado = 4,
    /// <summary>Operação concorrente ou estado incompatível (HTTP 409).</summary>
    Conflito = 5
}

/// <summary>
/// Resultado de um caso de uso: sucesso com valor ou falha com mensagem e categoria.
/// Evita usar exceções para fluxos esperados (ex.: senha inválida, batida fora de ordem).
/// </summary>
public sealed class Resultado<T>
{
    public bool Sucesso { get; }
    public T? Valor { get; }
    public string? Erro { get; }
    public TipoErro? TipoDoErro { get; }

    private Resultado(bool sucesso, T? valor, string? erro, TipoErro? tipo)
    {
        Sucesso = sucesso;
        Valor = valor;
        Erro = erro;
        TipoDoErro = tipo;
    }

    public static Resultado<T> Ok(T valor) => new(true, valor, null, null);

    /// <summary>Falha de validação (a categoria mais comum).</summary>
    public static Resultado<T> Falha(string erro) => Falha(TipoErro.Validacao, erro);

    public static Resultado<T> Falha(TipoErro tipo, string erro)
    {
        if (string.IsNullOrWhiteSpace(erro))
            throw new ArgumentException("A mensagem de erro é obrigatória.", nameof(erro));
        return new(false, default, erro, tipo);
    }
}

/// <summary>Resultado de um caso de uso que não devolve valor (ex.: alterar senha).</summary>
public sealed class Resultado
{
    public bool Sucesso { get; }
    public string? Erro { get; }
    public TipoErro? TipoDoErro { get; }

    private Resultado(bool sucesso, string? erro, TipoErro? tipo)
    {
        Sucesso = sucesso;
        Erro = erro;
        TipoDoErro = tipo;
    }

    public static Resultado Ok() => new(true, null, null);

    public static Resultado Falha(string erro) => Falha(TipoErro.Validacao, erro);

    public static Resultado Falha(TipoErro tipo, string erro)
    {
        if (string.IsNullOrWhiteSpace(erro))
            throw new ArgumentException("A mensagem de erro é obrigatória.", nameof(erro));
        return new(false, erro, tipo);
    }
}
```

```csharp
    public const string ImpressaoSenha = "ph";
    public const string FinalidadeRedefinicaoSenha = "redefinir-senha";

/// <summary>
/// "Impressão" da senha atual: 16 caracteres derivados do hash BCrypt gravado.
/// Vai dentro do token de redefinição; assim que a senha muda, o hash muda e o link antigo deixa de valer,
/// o que dá uso único ao token sem precisar de uma tabela (o modelo físico não tem).
/// </summary>
public static class ImpressaoSenha
{
    public static string De(string hashSenha)
    {
        var bytes = SHA256.HashData(Encoding.UTF8.GetBytes(hashSenha ?? string.Empty));
        return Convert.ToHexString(bytes, 0, 8).ToLowerInvariant();
    }

    /// <summary>Comparação em tempo constante.</summary>
    public static bool Confere(string hashSenhaAtual, string impressaoDoToken) =>
        CryptographicOperations.FixedTimeEquals(
            Encoding.ASCII.GetBytes(De(hashSenhaAtual)),
            Encoding.ASCII.GetBytes(impressaoDoToken ?? string.Empty));
}
```

```csharp
using HRAuto.Application.Common;
using HRAuto.Domain.Enums;
using HRAuto.Domain.ValueObjects;

namespace HRAuto.Application.Autenticacao;

/// <summary>Corpo de POST /auth/login. Campos opcionais para que a falta deles vire mensagem clara, não erro genérico.</summary>
public sealed record CredenciaisDto(string? Email, string? Senha);

public sealed record UsuarioAutenticadoDto(string Codigo, string Nome, string Email, string Perfil);

public sealed record LoginRespostaDto(string Token, DateTimeOffset ExpiraEm, UsuarioAutenticadoDto Usuario);

/// <summary>
/// Login com e-mail e senha (RF01, RNF04, RNF05). Devolve o token JWT com o perfil.
/// Cuidados de segurança:
/// - a mesma mensagem para e-mail inexistente, senha errada e conta inativa (não revela quem tem conta);
/// - conta inexistente também gasta um BCrypt, para o tempo de resposta não denunciar o e-mail;
/// - a conta inativa só é reconhecida depois de a senha estar correta;
/// - login e falha de login ficam no log de auditoria (RF08, RNF07).
/// </summary>
public sealed class AutenticarUsuario
{
    public const string MensagemCredenciaisInvalidas = "E-mail ou senha inválidos.";

    // Hash descartável para gastar o mesmo tempo do BCrypt quando o e-mail não existe. Criado uma vez por processo.
    private static string? _hashFalso;

    private readonly IUsuarioRepositorio _usuarios;
    private readonly IHashSenha _hash;
    private readonly IServicoToken _tokens;
    private readonly IAuditoria _auditoria;
    private readonly IUnidadeDeTrabalho _unidade;
    private readonly IRelogio _relogio;

    public AutenticarUsuario(
        IUsuarioRepositorio usuarios,
        IHashSenha hash,
        IServicoToken tokens,
        IAuditoria auditoria,
        IUnidadeDeTrabalho unidade,
        IRelogio relogio)
    {
        _usuarios = usuarios;
        _hash = hash;
        _tokens = tokens;
        _auditoria = auditoria;
        _unidade = unidade;
        _relogio = relogio;
    }

    public async Task<Resultado<LoginRespostaDto>> ExecutarAsync(CredenciaisDto? credenciais, CancellationToken cancelamento = default)
    {
        if (credenciais is null || string.IsNullOrWhiteSpace(credenciais.Email) || string.IsNullOrEmpty(credenciais.Senha))
            return Resultado<LoginRespostaDto>.Falha("Informe o e-mail e a senha.");

        // E-mail com formato inválido nunca existe no banco: mesma resposta de qualquer outra credencial inválida.
        if (!EmailUsuario.TentarNormalizar(credenciais.Email, out var email))
            return CredenciaisInvalidas();

        var usuario = await _usuarios.ObterPorEmailAsync(email, cancelamento);
        if (usuario is null)
        {
            _hash.Verificar(credenciais.Senha, ObterHashFalso());
            return CredenciaisInvalidas();
        }

        if (!_hash.Verificar(credenciais.Senha, usuario.Senha))
        {
            _auditoria.Registrar(usuario.Id, "LoginFalha", "USUARIO", usuario.Id, "Senha incorreta.");
            await _unidade.SalvarAsync(cancelamento);
            return CredenciaisInvalidas();
        }

        var funcionario = usuario.Funcionario;
        var perfilValido = Enum.IsDefined(typeof(PerfilAcesso), usuario.IdPerfil);
        if (!usuario.Ativo || funcionario is null || !funcionario.Ativo || !perfilValido)
        {
            _auditoria.Registrar(usuario.Id, "LoginNegado", "USUARIO", usuario.Id, "Usuário ou funcionário inativo.");
            await _unidade.SalvarAsync(cancelamento);
            return CredenciaisInvalidas();
        }

        var perfil = (PerfilAcesso)usuario.IdPerfil;
        usuario.UltimoLogin = _relogio.Agora().DateTime;
        _auditoria.Registrar(usuario.Id, "Login", "USUARIO", usuario.Id, null);
        await _unidade.SalvarAsync(cancelamento);

        var codigo = CodigoFuncionario.Formatar(funcionario.Id);
        var token = _tokens.GerarAcesso(new DadosToken(usuario.Id, funcionario.Id, codigo, funcionario.Nome, usuario.Email, perfil));

        return Resultado<LoginRespostaDto>.Ok(new LoginRespostaDto(
            token.Token,
            token.ExpiraEm,
            new UsuarioAutenticadoDto(codigo, funcionario.Nome, usuario.Email, NomesPerfil.De(perfil))));
    }

    private static Resultado<LoginRespostaDto> CredenciaisInvalidas() =>
        Resultado<LoginRespostaDto>.Falha(TipoErro.NaoAutenticado, MensagemCredenciaisInvalidas);

    private string ObterHashFalso() => _hashFalso ??= _hash.Gerar(Guid.NewGuid().ToString("N"));
}
```

```csharp
/// e avisa o gestor se as horas extras passaram do limite (RF25). Só marca as mudanças nos repositórios;
/// quem grava é o caso de uso que chamou, dentro da sua transação.
/// </summary>
public sealed class FechamentoDoDia
{
    private readonly IFuncionarioRepositorio _funcionarios;
    private readonly IFeriadoRepositorio _feriados;
    private readonly IFeriasRepositorio _ferias;
    private readonly IBancoHorasRepositorio _bancoHoras;

    private readonly JornadaPadrao _jornada;
    private readonly CalculadoraJornada _calculadora;
    private readonly IRelogio _relogio;

    public FechamentoDoDia(
        IFuncionarioRepositorio funcionarios,
        IFeriadoRepositorio feriados,
        IFeriasRepositorio ferias,
        IBancoHorasRepositorio bancoHoras,
        INotificacaoRepositorio notificacoes,
        JornadaPadrao jornada,
        CalculadoraJornada calculadora,
        IRelogio relogio)
    {
        _funcionarios = funcionarios;
        _feriados = feriados;
        _ferias = ferias;
        _bancoHoras = bancoHoras;
        _notificacoes = notificacoes;
        _jornada = jornada;
        _calculadora = calculadora;
        _relogio = relogio;
    }

    /// <param name="funcionario">Dono do ponto.</param>
    /// <param name="ponto">Ponto do dia, com as quatro batidas.</param>
    public async Task<ResumoDia> ExecutarAsync(Funcionario funcionario, Ponto ponto, CancellationToken cancelamento = default)
    {
        var dia = ponto.Data;

        // Feriados valem conforme a cidade/estado do funcionário (FUNCIONARIO_DETALHES).
        var detalhes = await _funcionarios.ObterDetalhesAsync(funcionario.Id, cancelamento);
        var feriados = await _feriados.ListarPeriodoAsync(dia, dia, cancelamento);
        var datasDeFeriado = ResolvedorContextoDia.DatasDeFeriadoAplicaveis(feriados, detalhes?.Cidade, detalhes?.Estado);
        var ferias = await _ferias.ListarAprovadasNoPeriodoAsync(funcionario.Id, dia, dia, cancelamento);

        var contexto = ResolvedorContextoDia.Resolver(dia, _jornada, ferias, datasDeFeriado);
        var resumo = _calculadora.Calcular(ponto, dia, contexto, diaEncerrado: true);

        // Idempotente: se o dia já tem lançamento de origem "Ponto", não cria outro.
        var existentes = await _bancoHoras.ListarDoDiaAsync(funcionario.Id, dia, cancelamento);
        var lancamento = RegrasBancoHoras.LancamentoDoDia(funcionario.Id, resumo, existentes);
        if (lancamento is not null) _bancoHoras.Adicionar(lancamento);

        if (funcionario.IdGestor is int idGestor && _calculadora.ExcedeLimiteHoraExtra(resumo))
        {
            _notificacoes.Adicionar(FabricaNotificacoes.HoraExtra(
                idGestor, funcionario.Id, resumo.HorasExtras, dia, _relogio.Agora().DateTime));
        }

        return resumo;
    }
```

```csharp
/// <summary>
/// Registrar ponto (RF17, RF18): grava a próxima batida do dia com a hora do SERVIDOR (o app não envia horário).
/// A sequência entrada -> saída p/ intervalo -> retorno -> saída é imposta pelo Domain (<see cref="Ponto.RegistrarBatida"/>).
/// Na 4ª batida o dia é fechado: banco de horas (RF24) e alerta de hora extra ao gestor (RF25).
/// </summary>
public sealed class RegistrarBatida
{
    private readonly IFuncionarioRepositorio _funcionarios;
    private readonly IPontoRepositorio _pontos;
    private readonly FechamentoDoDia _fechamento;
    private readonly IAuditoria _auditoria;
    private readonly IUnidadeDeTrabalho _unidade;
    private readonly IRelogio _relogio;

    public RegistrarBatida(
        IFuncionarioRepositorio funcionarios,
        IPontoRepositorio pontos,
        FechamentoDoDia fechamento,
        IAuditoria auditoria,
        IUnidadeDeTrabalho unidade,
        IRelogio relogio)
    {
        _funcionarios = funcionarios;
        _pontos = pontos;
        _fechamento = fechamento;
        _auditoria = auditoria;
        _unidade = unidade;
        _relogio = relogio;
    }

    public async Task<Resultado<BatidaRegistradaDto>> ExecutarAsync(Solicitante solicitante, CancellationToken cancelamento = default)
    {
        var funcionario = await _funcionarios.ObterPorIdAsync(solicitante.IdFuncionario, cancelamento);
        if (funcionario is null || !funcionario.Ativo)
            return Resultado<BatidaRegistradaDto>.Falha(TipoErro.Proibido, "Funcionário inativo ou não encontrado.");

        var agora = _relogio.Agora();
        var hoje = PontoMapeador.Dia(agora);
        var hora = PontoMapeador.Hora(agora);

        var ponto = await _pontos.ObterDoDiaAsync(funcionario.Id, hoje, cancelamento);
        var ehNovo = ponto is null;
        ponto ??= Ponto.Criar(funcionario.Id, hoje);

        TipoBatida tipo;
        try
        {
            tipo = ponto.RegistrarBatida(hora);
        }
        catch (DominioException e)
        {
            return Resultado<BatidaRegistradaDto>.Falha(e.Message); // fora de ordem, repetida ou 5ª batida
        }

        if (ehNovo) _pontos.Adicionar(ponto);

        ResumoDia? fechamento = null;
        try
        {
            // Duas gravações na mesma transação: a primeira gera o id do ponto, a segunda grava o log que o referencia.
            await using var transacao = await _unidade.IniciarTransacaoAsync(cancelamento);

            if (ponto.TotalBatidas() == 4)
                fechamento = await _fechamento.ExecutarAsync(funcionario, ponto, cancelamento);
            await _unidade.SalvarAsync(cancelamento);

            _auditoria.Registrar(
                solicitante.IdUsuario, "RegistrarPonto", "PONTO", ponto.Id,
                $"{CodigoFuncionario.Formatar(funcionario.Id)}: {Ponto.Nome(tipo)} às {hora:HH\\:mm\\:ss} de {hoje:dd/MM/yyyy}");
            await _unidade.SalvarAsync(cancelamento);

            await transacao.ConfirmarAsync(cancelamento);
        }
        catch (ConflitoDePersistenciaException)
        {
            return Resultado<BatidaRegistradaDto>.Falha(
                TipoErro.Conflito, "Outra batida foi registrada ao mesmo tempo. Atualize a tela e confira o ponto de hoje.");
        }

        return Resultado<BatidaRegistradaDto>.Ok(new BatidaRegistradaDto(
            tipo,
            Ponto.Nome(tipo),
            hoje,
            hora,
            ponto.ProximaBatida(),
            fechamento is null ? null : ResumoDiaDto.De(fechamento)));
    }
}
```

```csharp
using HRAuto.Application.Abstractions;
using HRAuto.Application.Common;
using HRAuto.Domain.Common;
using HRAuto.Domain.Entities;
using HRAuto.Domain.Enums;
using HRAuto.Domain.ValueObjects;

namespace HRAuto.Application.RegistroPonto;

/// <summary>
/// Sincroniza a fila de batidas feitas sem internet (RF19, RNF09). Cada item é avaliado sozinho: os válidos entram,
/// os inválidos voltam como "Recusada" com o motivo, e reenviar uma batida já gravada devolve "JaRegistrada" sem duplicar.
/// O horário vem do aparelho (o servidor não estava acessível), por isso há limites de segurança:
/// nada de data/horário futuro (com 2 min de folga para diferença de relógio) e nada com mais de 7 dias.
/// Batida mais antiga ou diferente da já gravada exige manutenção de ponto (RF22).
/// </summary>
public sealed class SincronizarBatidas
{
    public const int MaximoBatidasPorEnvio = 100;
    public const int DiasMaximosOffline = 7;
    public static readonly TimeSpan FolgaRelogioAparelho = TimeSpan.FromMinutes(2);

    private readonly IFuncionarioRepositorio _funcionarios;
    private readonly IPontoRepositorio _pontos;
    private readonly FechamentoDoDia _fechamento;
    private readonly IAuditoria _auditoria;
    private readonly IUnidadeDeTrabalho _unidade;
    private readonly IRelogio _relogio;

    public SincronizarBatidas(
        IFuncionarioRepositorio funcionarios,
        IPontoRepositorio pontos,
        FechamentoDoDia fechamento,
        IAuditoria auditoria,
        IUnidadeDeTrabalho unidade,
        IRelogio relogio)
    {
        _funcionarios = funcionarios;
        _pontos = pontos;
        _fechamento = fechamento;
        _auditoria = auditoria;
        _unidade = unidade;
        _relogio = relogio;
    }

    // Estado de um dia durante a sincronização.
    private sealed class DiaEmSincronizacao
    {
        public required Ponto Ponto { get; init; }
        public required bool Novo { get; init; }
        public int Aplicadas { get; set; }
    }

    public async Task<Resultado<IReadOnlyList<ResultadoBatidaOfflineDto>>> ExecutarAsync(
        Solicitante solicitante, SincronizarBatidasDto? dto, CancellationToken cancelamento = default)
    {
        if (dto?.Batidas is null || dto.Batidas.Count == 0)
            return Resultado<IReadOnlyList<ResultadoBatidaOfflineDto>>.Falha("Envie ao menos uma batida.");
        if (dto.Batidas.Count > MaximoBatidasPorEnvio)
            return Resultado<IReadOnlyList<ResultadoBatidaOfflineDto>>.Falha(
                $"Envie no máximo {MaximoBatidasPorEnvio} batidas por vez.");

        var funcionario = await _funcionarios.ObterPorIdAsync(solicitante.IdFuncionario, cancelamento);
        if (funcionario is null || !funcionario.Ativo)
            return Resultado<IReadOnlyList<ResultadoBatidaOfflineDto>>.Falha(
                TipoErro.Proibido, "Funcionário inativo ou não encontrado.");

        var agora = _relogio.Agora();
        var hoje = PontoMapeador.Dia(agora);
        var horaAgora = PontoMapeador.Hora(agora);

        var resultados = new ResultadoBatidaOfflineDto[dto.Batidas.Count];
        var dias = new Dictionary<DateOnly, DiaEmSincronizacao>();

        // Ordem cronológica e, no mesmo dia, a ordem da sequência (entrada ... saída), guardando a posição original.
        var ordem = dto.Batidas
            .Select((item, indice) => (item, indice))
            .OrderBy(x => x.item.Data ?? DateOnly.MaxValue)
            .ThenBy(x => x.item.Tipo ?? TipoBatida.Saida)
            .ThenBy(x => x.item.Horario ?? TimeOnly.MaxValue)
            .ToList();

        foreach (var (item, indice) in ordem)
        {
            resultados[indice] = await ProcessarAsync(item, funcionario, hoje, horaAgora, dias, cancelamento);
        }

        // Só grava os dias que mudaram. Pontos novos que ficaram vazios (todas as batidas recusadas) são descartados.
        var alterados = dias.Where(d => d.Value.Aplicadas > 0).OrderBy(d => d.Key).Select(d => d.Value).ToList();
        if (alterados.Count == 0)
            return Resultado<IReadOnlyList<ResultadoBatidaOfflineDto>>.Ok(resultados);

        try
        {
            await using var transacao = await _unidade.IniciarTransacaoAsync(cancelamento);

            foreach (var dia in alterados)
            {
                if (dia.Novo) _pontos.Adicionar(dia.Ponto);
                if (dia.Ponto.TotalBatidas() == 4)
                    await _fechamento.ExecutarAsync(funcionario, dia.Ponto, cancelamento);
            }
            await _unidade.SalvarAsync(cancelamento);

            foreach (var dia in alterados)
            {
                _auditoria.Registrar(
                    solicitante.IdUsuario, "SincronizarPonto", "PONTO", dia.Ponto.Id,
                    $"{CodigoFuncionario.Formatar(funcionario.Id)}: {dia.Aplicadas} batida(s) offline de {dia.Ponto.Data:dd/MM/yyyy}");
            }
            await _unidade.SalvarAsync(cancelamento);

            await transacao.ConfirmarAsync(cancelamento);
        }
        catch (ConflitoDePersistenciaException)
        {
            return Resultado<IReadOnlyList<ResultadoBatidaOfflineDto>>.Falha(
                TipoErro.Conflito, "O ponto foi alterado ao mesmo tempo. Tente sincronizar novamente.");
        }

        return Resultado<IReadOnlyList<ResultadoBatidaOfflineDto>>.Ok(resultados);
    }

    private async Task<ResultadoBatidaOfflineDto> ProcessarAsync(
        BatidaOfflineDto item,
        Funcionario funcionario,
        DateOnly hoje,
        TimeOnly horaAgora,
        Dictionary<DateOnly, DiaEmSincronizacao> dias,
        CancellationToken cancelamento)
    {
        ResultadoBatidaOfflineDto Recusar(string motivo) =>
            new(item.Data, item.Tipo, item.Horario, SituacaoItemOffline.Recusada, motivo);

        if (item.Data is null || item.Tipo is null || item.Horario is null)
            return Recusar("Informe data, tipo e horário da batida.");

        var data = item.Data.Value;
        var tipo = item.Tipo.Value;
        var horario = item.Horario.Value;

        if (!Enum.IsDefined(typeof(TipoBatida), tipo))
            return Recusar("Tipo de batida inválido.");
        if (data > hoje)
            return Recusar("A data da batida está no futuro.");
        if (data == hoje && horario.ToTimeSpan() > horaAgora.ToTimeSpan() + FolgaRelogioAparelho)
            return Recusar("O horário da batida está no futuro. Confira o relógio do aparelho.");
        if (data < hoje.AddDays(-DiasMaximosOffline))
            return Recusar($"A batida tem mais de {DiasMaximosOffline} dias. Solicite a manutenção de ponto.");
        if (data < funcionario.DataAdmissao)
            return Recusar("A data da batida é anterior à admissão.");

        if (!dias.TryGetValue(data, out var dia))
        {
            var existente = await _pontos.ObterDoDiaAsync(funcionario.Id, data, cancelamento);
            dia = new DiaEmSincronizacao
            {
                Ponto = existente ?? Ponto.Criar(funcionario.Id, data),
                Novo = existente is null
            };
            dias[data] = dia;
        }

        try
        {
            var resultado = dia.Ponto.AplicarBatidaSincronizada(tipo, horario);
            if (resultado == ResultadoSincronizacao.JaRegistrada)
                return new(data, tipo, horario, SituacaoItemOffline.JaRegistrada, null);

            dia.Aplicadas++;
            return new(data, tipo, horario, SituacaoItemOffline.Aplicada, null);
        }
        catch (DominioException e)
        {
            return Recusar(e.Message);
        }
    }
}
```

```csharp
using HRAuto.Application.Abstractions;
using HRAuto.Application.Common;
using HRAuto.Domain.Entities;

/// <summary>
/// Espelho de ponto (RF21): batidas e totais por período. Quem pode ver:
/// o colaborador, o próprio; o gestor, a equipe (quem tem ele como id_gestor); RH e Admin, todos (RNF06, RNF08).
/// Dias antes da admissão e dias futuros não aparecem. Sem datas informadas, devolve do dia 1 do mês até hoje.
/// </summary>
public sealed class ConsultarEspelhoPonto
{
    public const int MaximoDiasPorConsulta = 366;

    private readonly IFuncionarioRepositorio _funcionarios;
    private readonly IPontoRepositorio _pontos;
    private readonly IFeriadoRepositorio _feriados;
    private readonly IFeriasRepositorio _ferias;
    private readonly IBancoHorasRepositorio _bancoHoras;
    private readonly JornadaPadrao _jornada;
    private readonly CalculadoraJornada _calculadora;
    private readonly IRelogio _relogio;

    public ConsultarEspelhoPonto(
        IFuncionarioRepositorio funcionarios,
        IPontoRepositorio pontos,
        IFeriadoRepositorio feriados,
        IFeriasRepositorio ferias,
        IBancoHorasRepositorio bancoHoras,
        JornadaPadrao jornada,
        CalculadoraJornada calculadora,
        IRelogio relogio)
    {
        _funcionarios = funcionarios;
        _pontos = pontos;
        _feriados = feriados;
        _ferias = ferias;
        _bancoHoras = bancoHoras;
        _jornada = jornada;
        _calculadora = calculadora;
        _relogio = relogio;
    }

    /// <param name="codigo">FUNC-0001 do funcionário consultado; vazio = o próprio solicitante.</param>
    public async Task<Resultado<EspelhoPontoDto>> ExecutarAsync(
        Solicitante solicitante, string? codigo, DateOnly? de, DateOnly? ate, CancellationToken cancelamento = default)
    {
        var hoje = _relogio.Hoje();
        var inicio = de ?? new DateOnly(hoje.Year, hoje.Month, 1);
        var fim = ate ?? hoje;

        if (fim < inicio)
            return Resultado<EspelhoPontoDto>.Falha("A data final não pode ser anterior à inicial.");
        if (fim.DayNumber - inicio.DayNumber + 1 > MaximoDiasPorConsulta)
            return Resultado<EspelhoPontoDto>.Falha($"O período pode ter no máximo {MaximoDiasPorConsulta} dias.");

        var idAlvo = solicitante.IdFuncionario;
        if (!string.IsNullOrWhiteSpace(codigo))
        {
            if (!CodigoFuncionario.TentarConverter(codigo, out var codigoLido))
                return Resultado<EspelhoPontoDto>.Falha("Código inválido. Use o formato FUNC-0001.");
            idAlvo = codigoLido.Id;
        }

        var alvo = await _funcionarios.ObterPorIdAsync(idAlvo, cancelamento);
        if (alvo is null)
            return Resultado<EspelhoPontoDto>.Falha(TipoErro.NaoEncontrado, "Funcionário não encontrado.");

        var proprio = alvo.Id == solicitante.IdFuncionario;
        var daEquipe = alvo.IdGestor == solicitante.IdFuncionario;
        if (!proprio && !daEquipe && !solicitante.Perfil.EhRhOuAdmin())
            return Resultado<EspelhoPontoDto>.Falha(TipoErro.Proibido, "Você não tem permissão para ver o ponto deste funcionário.");

        var detalhes = await _funcionarios.ObterDetalhesAsync(alvo.Id, cancelamento);
        var pontos = (await _pontos.ListarPeriodoAsync(alvo.Id, inicio, fim, cancelamento)).ToDictionary(p => p.Data);
        var feriados = await _feriados.ListarPeriodoAsync(inicio, fim, cancelamento);
        var datasDeFeriado = ResolvedorContextoDia.DatasDeFeriadoAplicaveis(feriados, detalhes?.Cidade, detalhes?.Estado);
        var ferias = await _ferias.ListarAprovadasNoPeriodoAsync(alvo.Id, inicio, fim, cancelamento);

        var resumos = new List<ResumoDia>();
        var dias = new List<DiaEspelhoDto>();

        for (var dia = inicio; dia <= fim; dia = dia.AddDays(1))
        {
            pontos.TryGetValue(dia, out var ponto);

            // Antes da admissão e dias que ainda não aconteceram não entram no espelho (a menos que haja batida gravada).
            if (ponto is null && (dia < alvo.DataAdmissao || dia > hoje)) continue;

            var contexto = ResolvedorContextoDia.Resolver(dia, _jornada, ferias, datasDeFeriado);
            var resumo = _calculadora.Calcular(ponto, dia, contexto, diaEncerrado: dia < hoje);
            resumos.Add(resumo);

            dias.Add(new DiaEspelhoDto(
                dia, resumo.Contexto, resumo.Situacao,
                ponto?.Entrada, ponto?.SaidaIntervalo, ponto?.RetornoIntervalo, ponto?.Saida,
                ResumoDiaDto.Minutos(resumo.Trabalhado), ResumoDiaDto.Minutos(resumo.HorasExtras),
                ResumoDiaDto.Minutos(resumo.HorasFaltantes), ResumoDiaDto.Minutos(resumo.Atraso)));
        }

        var total = CalculadoraJornada.Totalizar(resumos);
        var totais = new TotaisEspelhoDto(
            ResumoDiaDto.Minutos(total.Trabalhado), ResumoDiaDto.Minutos(total.HorasExtras),
            ResumoDiaDto.Minutos(total.HorasFaltantes), ResumoDiaDto.Minutos(total.Atrasos),
            total.DiasTrabalhados, total.Faltas, total.DiasInconsistentes, ResumoDiaDto.Minutos(total.Saldo));

        var saldoBanco = RegrasBancoHoras.Saldo(await _bancoHoras.ListarTodosAsync(alvo.Id, cancelamento));

        return Resultado<EspelhoPontoDto>.Ok(new EspelhoPontoDto(
            CodigoFuncionario.Formatar(alvo.Id), alvo.Nome, inicio, fim, dias, totais, saldoBanco));
    }
}
```

```csharp
using HRAuto.Application.Abstractions;
using HRAuto.Application.Common;
using Microsoft.Data.Sqlite;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Storage;

namespace HRAuto.Infrastructure.Persistencia;

/// <summary>
/// Unidade de trabalho sobre o <see cref="HrAutoDbContext"/>. Os repositórios, a auditoria e esta classe
/// compartilham o mesmo contexto (escopo da requisição), então um SaveChanges grava tudo junto.
/// </summary>
public sealed class UnidadeDeTrabalho : IUnidadeDeTrabalho
{
    // Códigos estendidos do SQLite para violação de chave única.
    private const int SqliteConstraintPrimaryKey = 1555;
    private const int SqliteConstraintUnique = 2067;

    private readonly HrAutoDbContext _db;

    public UnidadeDeTrabalho(HrAutoDbContext db) => _db = db;

    public async Task SalvarAsync(CancellationToken cancelamento = default)
    {
        try
        {
            await _db.SaveChangesAsync(cancelamento);
        }
        catch (DbUpdateException e) when (e.InnerException is SqliteException
        {
            SqliteErrorCode: 19,
            SqliteExtendedErrorCode: SqliteConstraintUnique or SqliteConstraintPrimaryKey
        })
        {
            // Ex.: dois toques simultâneos tentando criar o PONTO do mesmo dia (índice único ux_ponto_func_data, RNF09).
            throw new ConflitoDePersistenciaException("Violação de chave única ao gravar.", e);
        }
    }

    public async Task<ITransacao> IniciarTransacaoAsync(CancellationToken cancelamento = default) =>
        new TransacaoEf(await _db.Database.BeginTransactionAsync(cancelamento));

    private sealed class TransacaoEf : ITransacao
    {
```

### backend/src/HRAuto.Infrastructure/Seguranca/OpcoesJwt.cs

```csharp
using System.Security.Cryptography;
using System.Text;
using Microsoft.IdentityModel.Tokens;

namespace HRAuto.Infrastructure.Seguranca;

/// <summary>
/// Configuração do JWT (seção "Jwt"). A chave NUNCA vai no appsettings.json versionado:
/// em desenvolvimento fica em appsettings.Development.json; em produção, na variável de ambiente Jwt__Chave.
/// </summary>
public sealed class OpcoesJwt
{
    public const string Secao = "Jwt";
    public const int TamanhoMinimoChaveBytes = 32;

    /// <summary>Segredo HMAC-SHA256 (mínimo de 32 caracteres/bytes).</summary>
    public string? Chave { get; set; }

    public string Emissor { get; set; } = "HR-Auto";

    /// <summary>Público do token de acesso (o app).</summary>
    public string PublicoAcesso { get; set; } = "hrauto-app";

    /// <summary>Público do token de redefinição de senha. Diferente do de acesso para que um nunca valha como o outro.</summary>
    public string PublicoRedefinicao { get; set; } = "hrauto-redefinicao-senha";

    /// <summary>Validade do token de acesso. Curta, porque o JWT sem estado não pode ser revogado antes de expirar.</summary>
    public int ExpiraMinutos { get; set; } = 480;

    /// <summary>Validade do link "Esqueci minha senha" (RF03: 30 minutos).</summary>
    public int RedefinicaoMinutos { get; set; } = 30;

    /// <summary>Falha cedo, na subida da API, se a configuração estiver incompleta ou insegura.</summary>
    public void Validar()
    {
        if (string.IsNullOrWhiteSpace(Chave) || Encoding.UTF8.GetByteCount(Chave) < TamanhoMinimoChaveBytes)
            throw new InvalidOperationException(
                $"Jwt:Chave deve ter pelo menos {TamanhoMinimoChaveBytes} caracteres. " +
                "Defina a variável de ambiente Jwt__Chave (ou use appsettings.Development.json em desenvolvimento).");
        if (ExpiraMinutos is < 5 or > 1440)
            throw new InvalidOperationException("Jwt:ExpiraMinutos deve estar entre 5 e 1440.");
        if (RedefinicaoMinutos is < 1 or > 60)
            throw new InvalidOperationException("Jwt:RedefinicaoMinutos deve estar entre 1 e 60.");
        if (string.IsNullOrWhiteSpace(Emissor) || string.IsNullOrWhiteSpace(PublicoAcesso) || string.IsNullOrWhiteSpace(PublicoRedefinicao))
            throw new InvalidOperationException("Jwt:Emissor, Jwt:PublicoAcesso e Jwt:PublicoRedefinicao são obrigatórios.");
        if (PublicoAcesso == PublicoRedefinicao)
            throw new InvalidOperationException("Jwt:PublicoAcesso e Jwt:PublicoRedefinicao devem ser diferentes.");
    }

    public SymmetricSecurityKey ChaveDeAcesso() => new(Encoding.UTF8.GetBytes(Chave!));

    /// <summary>Chave derivada (HMAC da chave principal): o token de redefinição é assinado com outra chave.</summary>
    public SymmetricSecurityKey ChaveDeRedefinicao() =>
        new(HMACSHA256.HashData(Encoding.UTF8.GetBytes(Chave!), Encoding.UTF8.GetBytes("hrauto/redefinicao-senha")));
}
```

### backend/src/HRAuto.Infrastructure/Seguranca/ServicoTokenJwt.cs

```csharp
using System.Globalization;
using System.IdentityModel.Tokens.Jwt;
using System.Security.Claims;
using HRAuto.Application.Abstractions;
using HRAuto.Application.Autenticacao;
using HRAuto.Domain.Enums;
using Microsoft.Extensions.Options;
using Microsoft.IdentityModel.Tokens;

namespace HRAuto.Infrastructure.Seguranca;

/// <summary>
/// Emite e lê os JWT do sistema (HS256). Há dois tipos de token, impossíveis de confundir:
/// - acesso: público "hrauto-app", chave principal, claims do usuário e perfil (validado pelo middleware JwtBearer);
/// - redefinição de senha: público próprio, chave derivada, claim de finalidade e a impressão da senha atual (uso único).
/// </summary>
public sealed class ServicoTokenJwt : IServicoToken
{
    private readonly OpcoesJwt _opcoes;
    private readonly IRelogio _relogio;
    private readonly JwtSecurityTokenHandler _manipulador = new();

    public ServicoTokenJwt(IOptions<OpcoesJwt> opcoes, IRelogio relogio)
    {
        _opcoes = opcoes.Value;
        _opcoes.Validar();
        _relogio = relogio;
    }

    public TokenAcesso GerarAcesso(DadosToken dados)
    {
        var emitidoEm = _relogio.Agora();
        var expiraEm = emitidoEm.AddMinutes(_opcoes.ExpiraMinutos);

        var claims = new[]
        {
            new Claim(NomesClaims.Usuario, dados.IdUsuario.ToString(CultureInfo.InvariantCulture)),
            new Claim(NomesClaims.Funcionario, dados.IdFuncionario.ToString(CultureInfo.InvariantCulture)),
            new Claim(NomesClaims.Codigo, dados.Codigo),
            new Claim(NomesClaims.Nome, dados.Nome),
            new Claim(NomesClaims.Email, dados.Email),
            new Claim(NomesClaims.Perfil, NomesPerfil.De(dados.Perfil)),
            new Claim(JwtRegisteredClaimNames.Jti, Guid.NewGuid().ToString("N"))
        };

        var token = Criar(claims, _opcoes.PublicoAcesso, _opcoes.ChaveDeAcesso(), emitidoEm, expiraEm);
        return new TokenAcesso(token, expiraEm);
    }

    public string GerarRedefinicaoSenha(int idUsuario, string impressaoSenha)
    {
        var emitidoEm = _relogio.Agora();
        var expiraEm = emitidoEm.AddMinutes(_opcoes.RedefinicaoMinutos);

        var claims = new[]
        {
            new Claim(NomesClaims.Usuario, idUsuario.ToString(CultureInfo.InvariantCulture)),
            new Claim(NomesClaims.Finalidade, NomesClaims.FinalidadeRedefinicaoSenha),
            new Claim(NomesClaims.ImpressaoSenha, impressaoSenha)
        };

        return Criar(claims, _opcoes.PublicoRedefinicao, _opcoes.ChaveDeRedefinicao(), emitidoEm, expiraEm);
    }

    public bool TentarLerRedefinicaoSenha(string token, out int idUsuario, out string impressaoSenha)
    {
        idUsuario = 0;
        impressaoSenha = string.Empty;
        if (string.IsNullOrWhiteSpace(token) || token.Length > 2048) return false;

        // A validade é conferida à mão, com o relógio do sistema (IRelogio), para ser testável.
        var parametros = new TokenValidationParameters
        {
            ValidateIssuer = true,
            ValidIssuer = _opcoes.Emissor,
            ValidateAudience = true,
            ValidAudience = _opcoes.PublicoRedefinicao,
            ValidateIssuerSigningKey = true,
            IssuerSigningKey = _opcoes.ChaveDeRedefinicao(),
            ValidAlgorithms = new[] { SecurityAlgorithms.HmacSha256 },
            RequireSignedTokens = true,
            RequireExpirationTime = true,
            ValidateLifetime = false,
            ClockSkew = TimeSpan.Zero
        };

        try
        {
            _manipulador.ValidateToken(token, parametros, out var validado);
            if (validado is not JwtSecurityToken jwt) return false;
            if (jwt.ValidTo <= _relogio.Agora().UtcDateTime) return false;

            string? Valor(string tipo) => jwt.Claims.FirstOrDefault(c => c.Type == tipo)?.Value;

            if (Valor(NomesClaims.Finalidade) != NomesClaims.FinalidadeRedefinicaoSenha) return false;
            if (!int.TryParse(Valor(NomesClaims.Usuario), NumberStyles.None, CultureInfo.InvariantCulture, out var id) || id <= 0)
                return false;
            var impressao = Valor(NomesClaims.ImpressaoSenha);
            if (string.IsNullOrEmpty(impressao)) return false;

            idUsuario = id;
            impressaoSenha = impressao;
            return true;
        }
        catch (Exception e) when (e is SecurityTokenException or ArgumentException)
        {
            return false; // assinatura, público, formato ou algoritmo inválidos
        }
    }

    private string Criar(IEnumerable<Claim> claims, string publico, SecurityKey chave, DateTimeOffset emitidoEm, DateTimeOffset expiraEm)
    {
        var descritor = new SecurityTokenDescriptor
        {
            Subject = new ClaimsIdentity(claims),
            Issuer = _opcoes.Emissor,
            Audience = publico,
            IssuedAt = emitidoEm.UtcDateTime,
            NotBefore = emitidoEm.UtcDateTime,
            Expires = expiraEm.UtcDateTime,
            SigningCredentials = new SigningCredentials(chave, SecurityAlgorithms.HmacSha256)
        };
        return _manipulador.WriteToken(_manipulador.CreateToken(descritor));
    }
}
```

```csharp
/// <summary>
/// Envio real por SMTP (System.Net.Mail). Nunca lança exceção para o chamador: a resposta de "Esqueci minha senha"
/// não pode mudar conforme o envio dê certo (isso revelaria quais e-mails existem). Falhas vão para o log, sem o corpo.
/// </summary>

    private readonly OpcoesEmail _opcoes;

            if (!string.IsNullOrWhiteSpace(_opcoes.Usuario))
                cliente.Credentials = new NetworkCredential(_opcoes.Usuario, _opcoes.Senha);

            using var mensagem = new MailMessage(_opcoes.Remetente, destinatario, assunto, corpo);
            await cliente.SendMailAsync(mensagem, cancelamento);

        {

    }
```

### backend/src/HRAuto.Api/Seguranca/ClaimsPrincipalExtensoes.cs

```csharp
using System.Diagnostics.CodeAnalysis;
using System.Globalization;
using System.Security.Claims;
using HRAuto.Application.Autenticacao;
using HRAuto.Application.Common;
using HRAuto.Domain.Enums;

namespace HRAuto.Api.Seguranca;

public static class ClaimsPrincipalExtensoes
{
    /// <summary>
    /// Monta o <see cref="Solicitante"/> a partir das claims do token já validado (sub, fid, role).
    /// Devolve false se alguma claim faltar ou for inválida: nesse caso o controller responde 401,
    /// em vez de deixar a Application trabalhar com identidade incompleta.
    /// </summary>
    public static bool TentarObterSolicitante(this ClaimsPrincipal principal, [NotNullWhen(true)] out Solicitante? solicitante)
    {
        solicitante = null;

        if (!TentarInteiro(principal.FindFirst(NomesClaims.Usuario)?.Value, out var idUsuario)) return false;
        if (!TentarInteiro(principal.FindFirst(NomesClaims.Funcionario)?.Value, out var idFuncionario)) return false;
        if (!PerfilAcessoExtensoes.TentarLer(principal.FindFirst(NomesClaims.Perfil)?.Value, out var perfil)) return false;

        solicitante = new Solicitante(idUsuario, idFuncionario, perfil);
        return true;
    }

    private static bool TentarInteiro(string? texto, out int valor) =>
        int.TryParse(texto, NumberStyles.None, CultureInfo.InvariantCulture, out valor) && valor > 0;
}
```

```csharp
namespace HRAuto.Api.Seguranca;

/// <summary>Regras de validação do token de acesso, usadas pelo middleware JwtBearer.</summary>
public static class ParametrosJwt
{
    public static TokenValidationParameters Acesso(OpcoesJwt configuracao, IRelogio relogio) => new()
    {
        ValidateIssuer = true,
        ValidIssuer = configuracao.Emissor,
        ValidateAudience = true,
        ValidAudience = configuracao.PublicoAcesso, // o token de redefinição de senha tem outro público e é recusado aqui
        ValidateIssuerSigningKey = true,
        IssuerSigningKey = configuracao.ChaveDeAcesso(),
        ValidAlgorithms = new[] { SecurityAlgorithms.HmacSha256 },
        RequireSignedTokens = true,
        RequireExpirationTime = true,
        ValidateLifetime = true,
        ClockSkew = TimeSpan.FromSeconds(30),
        NameClaimType = NomesClaims.Nome,
        RoleClaimType = NomesClaims.Perfil,
        // A validade é conferida com o IRelogio do sistema (o mesmo que emitiu o token), não com o relógio da máquina.
        LifetimeValidator = (naoAntesDe, expiraEm, _, parametros) =>
        {
            if (expiraEm is null) return false;
            var agora = relogio.Agora().UtcDateTime;
            if (naoAntesDe is not null && naoAntesDe.Value > agora + parametros.ClockSkew) return false;
            return expiraEm.Value + parametros.ClockSkew > agora;
        }
    };
```

### backend/src/HRAuto.Api/Controllers/ApiControllerBase.cs

```csharp
using System.Diagnostics.CodeAnalysis;
using HRAuto.Api.Seguranca;
using HRAuto.Application.Common;
using Microsoft.AspNetCore.Mvc;

namespace HRAuto.Api.Controllers;

/// <summary>
/// Base dos controllers autenticados. Converte o <see cref="Resultado{T}"/> da Application em resposta HTTP
/// (ProblemDetails, RFC 7807) para que o app Flutter trate todos os erros do mesmo jeito.
/// A segurança é "fechada por padrão": a política de fallback exige login em tudo que não tiver [AllowAnonymous].
/// </summary>
[ApiController]
public abstract class ApiControllerBase : ControllerBase
{
    /// <summary>Quem está chamando, lido do token. Falso = token válido mas com claims incompletas (responder 401).</summary>
    protected bool TentarObterSolicitante([NotNullWhen(true)] out Solicitante? solicitante) =>
        User.TentarObterSolicitante(out solicitante);

    protected ActionResult SessaoInvalida() =>
        Falha(TipoErro.NaoAutenticado, "Sessão inválida. Entre novamente.");

    /// <summary>200 com o valor, ou o erro correspondente.</summary>
    protected ActionResult Responder<T>(Resultado<T> resultado) =>
        resultado.Sucesso ? Ok(resultado.Valor) : Falha(resultado.TipoDoErro, resultado.Erro);

    /// <summary>Status de sucesso escolhido pelo controller (ex.: 201), ou o erro correspondente.</summary>
    protected ActionResult Responder<T>(Resultado<T> resultado, int statusSucesso) =>
        resultado.Sucesso ? StatusCode(statusSucesso, resultado.Valor) : Falha(resultado.TipoDoErro, resultado.Erro);

    /// <summary>204 sem corpo, ou o erro correspondente.</summary>
    protected ActionResult Responder(Resultado resultado) =>
        resultado.Sucesso ? NoContent() : Falha(resultado.TipoDoErro, resultado.Erro);

    protected ActionResult Falha(TipoErro? tipo, string? detalhe)
    {
        var (status, titulo) = tipo switch
        {
            TipoErro.Validacao => (StatusCodes.Status400BadRequest, "Dados inválidos"),
            TipoErro.NaoAutenticado => (StatusCodes.Status401Unauthorized, "Não autenticado"),
            TipoErro.Proibido => (StatusCodes.Status403Forbidden, "Acesso negado"),
            TipoErro.NaoEncontrado => (StatusCodes.Status404NotFound, "Não encontrado"),
            TipoErro.Conflito => (StatusCodes.Status409Conflict, "Conflito"),
            _ => (StatusCodes.Status500InternalServerError, "Erro interno")
        };

        if (status == StatusCodes.Status401Unauthorized)
            Response.Headers.WWWAuthenticate = "Bearer";

        // Erro interno nunca devolve detalhe vindo da Application.
        return Problem(
            title: titulo,
            detail: status == StatusCodes.Status500InternalServerError ? "Ocorreu um erro inesperado." : detalhe,
            statusCode: status);
    }
}
```

```csharp
using HRAuto.Api.Extensoes;
using HRAuto.Application.Autenticacao;
using Microsoft.AspNetCore.Authorization;
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.RateLimiting;

namespace HRAuto.Api.Controllers;

/// <summary>Resposta simples com uma mensagem para o usuário.</summary>
public sealed record MensagemDto(string Mensagem);

/// <summary>
/// Autenticação (RF01 a RF04). Login, "esqueci a senha" e redefinição são anônimos e têm limite de tentativas
/// por IP (força bruta) e corpo pequeno. Logout e troca de senha exigem token.
/// </summary>
[Route("api/v1/auth")]
public class AuthController : ApiControllerBase
{
    private const int LimiteCorpoBytes = 16 * 1024;

    /// <summary>Entra com e-mail e senha e recebe o token JWT (válido por 8 h) com o perfil do usuário.</summary>
    [HttpPost("login")]
    [AllowAnonymous]
    [EnableRateLimiting(PoliticasLimite.Autenticacao)]
    [RequestSizeLimit(LimiteCorpoBytes)]
    [ProducesResponseType(typeof(LoginRespostaDto), StatusCodes.Status200OK)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]
    [ProducesResponseType(StatusCodes.Status429TooManyRequests)]
    public async Task<ActionResult> Login([FromBody] CredenciaisDto credenciais, [FromServices] AutenticarUsuario caso, CancellationToken ct) =>
        Responder(await caso.ExecutarAsync(credenciais, ct));

    /// <summary>Registra o logout na auditoria. O app apaga o token do aparelho (RF02).</summary>
    [HttpPost("logout")]
    [ProducesResponseType(StatusCodes.Status204NoContent)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]
    public async Task<ActionResult> Logout([FromServices] EncerrarSessao caso, CancellationToken ct)
    {
        if (!TentarObterSolicitante(out var solicitante)) return SessaoInvalida();
        return Responder(await caso.ExecutarAsync(solicitante, ct));
    }

    /// <summary>O usuário logado troca a própria senha informando a atual (RF04).</summary>
    [HttpPost("alterar-senha")]
    [RequestSizeLimit(LimiteCorpoBytes)]
    [ProducesResponseType(StatusCodes.Status204NoContent)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status401Unauthorized)]
    public async Task<ActionResult> AlterarSenha([FromBody] AlterarSenhaDto dto, [FromServices] AlterarSenha caso, CancellationToken ct)
    {
        if (!TentarObterSolicitante(out var solicitante)) return SessaoInvalida();
        return Responder(await caso.ExecutarAsync(solicitante, dto, ct));
    }

    /// <summary>
    /// Pede o e-mail de recuperação (RF03). Responde 202 com a mesma mensagem exista ou não a conta,
    /// para não revelar quais e-mails estão cadastrados.
    /// </summary>
    [HttpPost("esqueci-senha")]
    [AllowAnonymous]
    [EnableRateLimiting(PoliticasLimite.Autenticacao)]
    [RequestSizeLimit(LimiteCorpoBytes)]
    [ProducesResponseType(typeof(MensagemDto), StatusCodes.Status202Accepted)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status429TooManyRequests)]
    public async Task<ActionResult> EsqueciSenha([FromBody] SolicitarRecuperacaoDto dto, [FromServices] RecuperarSenha caso, CancellationToken ct)
    {
        var resultado = await caso.SolicitarAsync(dto, ct);
        return resultado.Sucesso
            ? Accepted(new MensagemDto(RecuperarSenha.MensagemSolicitacao))
            : Falha(resultado.TipoDoErro, resultado.Erro);
    }

    /// <summary>Define a nova senha com o token recebido por e-mail (uso único, 30 minutos).</summary>
    [HttpPost("redefinir-senha")]
    [AllowAnonymous]
    [EnableRateLimiting(PoliticasLimite.Autenticacao)]
    [RequestSizeLimit(LimiteCorpoBytes)]
    [ProducesResponseType(StatusCodes.Status204NoContent)]
    [ProducesResponseType(StatusCodes.Status400BadRequest)]
    [ProducesResponseType(StatusCodes.Status429TooManyRequests)]
    public async Task<ActionResult> RedefinirSenha([FromBody] RedefinirSenhaDto dto, [FromServices] RecuperarSenha caso, CancellationToken ct) =>
        Responder(await caso.RedefinirAsync(dto, ct));
}
```

### backend/src/HRAuto.Api/Middleware/TratadorDeExcecoes.cs

```csharp
using HRAuto.Application.Common;
using HRAuto.Domain.Common;
using Microsoft.AspNetCore.Diagnostics;
using Microsoft.AspNetCore.Mvc;

namespace HRAuto.Api.Middleware;

/// <summary>
/// Última rede de proteção: transforma exceções não tratadas em ProblemDetails (RFC 7807) sem vazar detalhes internos.
/// - DominioException (regra de negócio violada que escapou do caso de uso) -> 400
/// - ConflitoDePersistenciaException (índice único / concorrência) -> 409
/// - BadHttpRequestException (corpo grande demais, JSON quebrado) -> o status dela, com mensagem genérica
/// - qualquer outra -> 500 genérico; o stack trace vai só para o log, com o traceId que também volta ao cliente.
/// </summary>
public sealed class TratadorDeExcecoes : IExceptionHandler
{
    private readonly ILogger<TratadorDeExcecoes> _log;

    public TratadorDeExcecoes(ILogger<TratadorDeExcecoes> log) => _log = log;

    public async ValueTask<bool> TryHandleAsync(HttpContext contexto, Exception excecao, CancellationToken cancelamento)
    {
        var (status, titulo, detalhe) = excecao switch
        {
            DominioException e => (StatusCodes.Status400BadRequest, "Dados inválidos", e.Message),
            ConflitoDePersistenciaException e => (StatusCodes.Status409Conflict, "Conflito", e.Message),
            BadHttpRequestException e => (e.StatusCode, "Requisição inválida", "Não foi possível ler a requisição."),
            _ => (StatusCodes.Status500InternalServerError, "Erro interno", "Ocorreu um erro inesperado. Tente novamente em instantes.")
        };

        if (status >= 500)
            _log.LogError(excecao, "Erro não tratado em {Metodo} {Caminho} (traceId {TraceId})",
                contexto.Request.Method, contexto.Request.Path, contexto.TraceIdentifier);
        else
            _log.LogWarning("Requisição recusada ({Status}) em {Metodo} {Caminho}: {Tipo}",
                status, contexto.Request.Method, contexto.Request.Path, excecao.GetType().Name);

        var problema = new ProblemDetails { Status = status, Title = titulo, Detail = detalhe };
        problema.Extensions["traceId"] = contexto.TraceIdentifier;

        contexto.Response.StatusCode = status;
        await contexto.Response.WriteAsJsonAsync(problema, options: null, contentType: "application/problem+json", cancellationToken: cancelamento);
        return true;
    }
}
```

```csharp
/// <summary>
/// Configuração da camada Api, dividida em métodos para o Program.cs ficar legível.
/// Tudo que lê configuração (chave JWT, limites, origens) o faz de forma preguiçosa, via IOptions,
/// para que variáveis de ambiente e as configurações dos testes de integração já estejam carregadas.
/// </summary>
public static class ServicosExtensoes
{
    public const string PoliticaCorsFlutter = "Flutter";

    /// <summary>Controllers com JSON em padrão ISO 8601 e enums escritos por nome (ex.: "Entrada").</summary>
    public static IServiceCollection AddControllersDaApi(this IServiceCollection services)
    {
        services.AddControllers().AddJsonOptions(opcoes =>
            opcoes.JsonSerializerOptions.Converters.Add(new JsonStringEnumConverter()));
        return services;
    }

    /// <summary>
    /// Seguro por padrão: toda rota exige login, a menos que tenha [AllowAnonymous]. Assim, um endpoint novo
    /// esquecido sem atributo nunca fica público por engano.
    /// </summary>
    public static IServiceCollection AddAutorizacao(this IServiceCollection services)
    {
        services.AddAuthorization(opcoes =>
        {
            opcoes.FallbackPolicy = new AuthorizationPolicyBuilder().RequireAuthenticatedUser().Build();
            opcoes.AddPolicy(Papeis.PoliticaRhOuAdmin, p => p.RequireAuthenticatedUser().RequireRole(NomesPerfil.RH, NomesPerfil.Admin));
            opcoes.AddPolicy(Papeis.PoliticaAdmin, p => p.RequireAuthenticatedUser().RequireRole(NomesPerfil.Admin));
        });
        return services;
    }

    /// <summary>Limite de tentativas de login/recuperação por IP (força bruta). Responde 429 com Retry-After.</summary>
    public static IServiceCollection AddLimiteDeRequisicoes(this IServiceCollection services)
    {
        services.AddOptions<OpcoesLimiteRequisicoes>().BindConfiguration(OpcoesLimiteRequisicoes.Secao);

        services.AddRateLimiter(opcoes =>
        {
            opcoes.RejectionStatusCode = StatusCodes.Status429TooManyRequests;

            opcoes.AddPolicy(PoliticasLimite.Autenticacao, contexto =>
            {
                var configuracao = contexto.RequestServices.GetRequiredService<IOptions<OpcoesLimiteRequisicoes>>().Value;
                var chave = contexto.Connection.RemoteIpAddress?.ToString() ?? "desconhecido";

                return RateLimitPartition.GetFixedWindowLimiter(chave, _ => new FixedWindowRateLimiterOptions
                {
                    PermitLimit = Math.Max(1, configuracao.AutenticacaoLimite),
                    Window = TimeSpan.FromSeconds(Math.Max(1, configuracao.AutenticacaoJanelaSegundos)),
                    QueueLimit = 0,
                    AutoReplenishment = true
                });
            });

            opcoes.OnRejected = async (rejeicao, cancelamento) =>
            {
                var resposta = rejeicao.HttpContext.Response;
                resposta.StatusCode = StatusCodes.Status429TooManyRequests;
                if (rejeicao.Lease.TryGetMetadata(MetadataName.RetryAfter, out var espera))
                    resposta.Headers.RetryAfter = ((int)Math.Ceiling(espera.TotalSeconds)).ToString(CultureInfo.InvariantCulture);

                await resposta.WriteAsJsonAsync(
                    new ProblemDetails
                    {
                        Status = StatusCodes.Status429TooManyRequests,
                        Title = "Muitas tentativas",
                        Detail = "Muitas tentativas em pouco tempo. Aguarde um instante e tente de novo."
                    },
                    options: null,
                    contentType: "application/problem+json",
                    cancellationToken: cancelamento);
            };
        });
        return services;
    }

    /// <summary>
    /// CORS: com <c>Cors:Origens</c> configurado (produção) só essas origens passam; sem configuração,
    /// só localhost (Flutter Web em desenvolvimento, porta aleatória).
    /// </summary>
    public static IServiceCollection AddCorsFlutter(this IServiceCollection services)
    {
        services.AddOptions<OpcoesCors>().BindConfiguration(OpcoesCors.Secao);

        services.AddOptions<CorsOptions>().Configure<IOptions<OpcoesCors>>((cors, opcoes) =>
        {
            var origens = opcoes.Value.Origens.Where(o => !string.IsNullOrWhiteSpace(o)).ToArray();
            cors.AddPolicy(PoliticaCorsFlutter, politica =>
            {
                if (origens.Length > 0)
                    politica.WithOrigins(origens);
                else
                    politica.SetIsOriginAllowed(origem => Uri.TryCreate(origem, UriKind.Absolute, out var uri) && uri.IsLoopback);

                politica.AllowAnyHeader().AllowAnyMethod();
            });
        });
        services.AddCors();
        return services;
    }

    /// <summary>
    /// Endereço da tela de redefinição de senha, usado no link do e-mail (RF03). Vem SEMPRE da configuração,
    /// nunca do cabeçalho Host da requisição (evita link de recuperação apontando para site de terceiros).
    /// </summary>
    public static IServiceCollection AddOpcoesRecuperacaoSenha(this IServiceCollection services)
    {
        services.AddSingleton(provedor =>
        {
            var url = provedor.GetRequiredService<IConfiguration>()["App:UrlRedefinicaoSenha"];
            if (string.IsNullOrWhiteSpace(url)
                || !Uri.TryCreate(url, UriKind.Absolute, out var uri)
                || (uri.Scheme != Uri.UriSchemeHttp && uri.Scheme != Uri.UriSchemeHttps))
                throw new InvalidOperationException(
                    "App:UrlRedefinicaoSenha deve ser uma URL http(s) completa da tela de redefinição de senha do app " +
                    "(ex.: https://rh.suaempresa.com.br/#/redefinir-senha). Defina a variável de ambiente App__UrlRedefinicaoSenha.");

            return new OpcoesRecuperacaoSenha(url.Trim());
        });
        return services;
    }
}
```

```csharp
        return (await resposta.Content.ReadFromJsonAsync<LoginRespostaDto>(Json))!.Token;
```
